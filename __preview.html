About

Engineering that holds up after the demo

I lead technical direction on a Laravel-based fintech CRM at Finovation Tech — owning architecture, workflow standards and delivery across the team. Before that I spent four years as a senior developer taking on the work nobody else wanted: legacy rebuilds, 8-minute page loads, N+1 queries buried three layers deep.

Most of what I'm proud of is unglamorous. A React grid that choked on 100k rows now renders in 45 seconds instead of eight minutes. A CRM rebuilt on Laravel + React that cut support tickets by 40%. A PHP 5.6 codebase upgraded to Laravel 8 without stopping feature work. The pattern is the same each time — find the real bottleneck, fix it properly, keep the team shipping while it happens.

Lately my focus has shifted to AI-assisted development: orchestrating specialised agents across spec, planning and implementation phases with Claude Code and Codex, and driving adoption of spec-driven development (BMAD Method, OpenSpec) so specifications — not prompts — are the source of truth. It cuts rework, and it keeps architecture consistent when several developers work in parallel.

I work directly with stakeholders, mentor the developers around me, and review code like it's going to outlive me. Comfortable remote, comfortable leading.
